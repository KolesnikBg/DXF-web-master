# DXF-web-master

Веб-сервис для загрузки и обработки файлов формата `.dxf` с чертежом, в котором имеются различные сущности (окружности, линии и другое), и возврашает в структурированном виде объекты заданного типа.

## Технологический стек

### Фронтенд

Простая веб страничка с формой в которой реализованно:

1. Форма загрузки файла формата `.dxf`.
1. Вывод типа сушностей для просмотра конкретных типов.
1. Информация об окружностях со всеми параметрами.

**Технологии:**

1. React
1. JS
1. HTML
1. CSS (SCSS если будет время)

### Бэк

Выполняет следующий функционал:

1. Загрузка файла формата `.dxf`.
1. Получение списка типов сущностей, которые есть в загруженном файле.
1. Получение списка объектов выбранного типа сущности

**Технологии:**

1. Python
    1. `ezdxf` - обработчик файла формата `.dxf`.
2. FastAPI - `fastapi`
    1. `unicorn` - сервер для запуска FastAPI-приложения.
    1. `python-multipart` - загрузка файлов.
